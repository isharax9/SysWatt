# Security policy

SysWatt `0.x` receives security fixes on the latest minor line. Please do not publish suspected vulnerabilities or diagnostic reports containing sensitive device labels. Report them privately through the repository host's security-advisory feature. Include impact, reproduction, and affected version; maintainers should acknowledge within seven days.

SysWatt does not require permanent elevation, send telemetry, or contact a network service. A vulnerability that violates those properties is considered high priority.
